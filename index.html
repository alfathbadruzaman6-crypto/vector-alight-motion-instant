PANDUAN ALIGHT MOTION

Cara Memasukkan Hasil ke Alight Motion

  1. 1. Pilih Sumber (Upload SVG, Foto ke SVG, atau Paste Kode)

    Unggah file .svg, unggah foto (JPG/PNG/WEBP) agar otomatis diubah menjadi jalur/path SVG, atau tempel kode SVG langsung.

  2. 2. Cek Batas Ukuran Paket (< 5.00 MB)

    Alight Motion memiliki batas preset/proyek yang nyaman di bawah 5.00 MB. Aktifkan Optimasi Path Otomatis bila jumlah path sangat besar.

  3. 3. Unduh File .xml atau Preset (< 5 MB)

    Klik Unduh .XML untuk proyek XML Alight Motion atau Unduh Preset (< 5 MB) untuk paket preset terkompresi.

  4. 4. Impor ke Aplikasi Alight Motion

    Buka file .xml dari pengelola berkas/unduhan lalu pilih Bagikan / Buka di Alight Motion. Setiap elemen vektor akan masuk sebagai layer <shape> di dalam proyek <amml>.
